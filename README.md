# Jenkins and Apache HTTPD Deployment – Assignment 1

## 1. Project Objective
To automate the deployment of an HTML webpage from a GitHub repository to an Apache HTTPD web server using Jenkins.

## 2. Tools and Technologies Used
- AWS EC2
- Amazon Linux 2023
- Git and GitHub
- Jenkins
- Apache HTTPD
- HTML

## 3. GitHub Repository
Repository Name: `jenkins-apache-assignment`

Branch: `main`

File: `index.html`

## 4. Project Workflow
1. Create an HTML webpage.
2. Push the source code to GitHub.
3. Configure a Jenkins Freestyle project.
4. Connect Jenkins to the GitHub repository.
5. Configure a shell build step to deploy the HTML file to the Apache web directory.
6. Access the deployed webpage through the EC2 public IP.

## 5. Expected Output
The webpage should display:

**Welcome to Jenkins Apache Deployment!**

Assignment 1

This webpage is deployed using Jenkins.
